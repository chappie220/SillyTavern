# SillyTavern

LLM Frontend for Power Users

支持 ST Agent Gateway、持久 main 主会话、心跳/定时任务与 QQ 官方机器人接入。使用 `npm run start:gateway` 可跳过前端编译和浏览器，直接运行服务端网关。参见 [配置说明](docs/st-agent-qq.md)。
